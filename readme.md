## 🛠️ Core Technical Focus & Skills
* **Database System:** MySQL / MariaDB Engine
* **Query Design:** Writing clean, readable queries with precise table and column aliases.
* **Referential Integrity:** Enforcing robust relationships using strict Primary and Foreign Key configurations (`ON DELETE CASCADE` / `SET NULL`).
* **Advanced Logic:** Handling complex subqueries, Common Table Expressions (CTEs), and specialized transactional database data types like `JSON` and `UUID`.
